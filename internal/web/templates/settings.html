Storage

Chosen before the app starts, so shown here but not editable.

{{range .Store}}{{template "stpRow" .}}{{end}}
Use Postgres or another location

The store is picked when rabbithole starts, so changing it takes a restart. Set these in your shell profile or in .env, then start rabbithole again:

RABBITHOLE_DB=postgres://user@host:5432/rabbithole
RABBITHOLE_DB_PASSWORD=your-password

The database must already exist; rabbithole creates its tables on first start. A password in the URL also works, but is not recommended.

For a SQLite file somewhere else, set RABBITHOLE_DB=/path/to/rabbithole.db or start with --db /path/to/rabbithole.db.

A new store starts empty. Run rabbithole config export and rabbithole sources export first to carry your settings and feeds over.
